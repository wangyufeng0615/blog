## 生成入口

在博客根目录执行 `node scripts/outer-wilds-clues/gen.mjs`。`OW_TEXT_DIR`可指定提取语料目录；默认读取本机Vault的`生活/游戏/Outer Wilds/`。这条命令只读取语料，生成专题文件，不执行发布或改写Vault原文。

常规本地预览可在博客根目录依次执行：

```sh
node scripts/outer-wilds-clues/gen.mjs
node --test scripts/outer-wilds-clues/topic.test.mjs
node scripts/build.js
python3 -m http.server 59047 --bind 127.0.0.1 --directory dist
```

随后在已登录Chrome打开`http://127.0.0.1:59047/outer-wilds-clues/`，人物和DLC锚点为`#nomai`、`#dlc`。构建会更新本地`dist/`；服务仅监听本机。生成器会刷新页面修改时间，不应为文档整理反复运行并引入无关时间戳改动。此前在Vault外复制文章和构建源码进行的隔离预览仍是历史验证现场，不代表服务当前运行。

## 事实、来源与联系语义

以`中英对照与结构.json`为第一来源，保留外星站全部98条日志文本记录及条件变体；卫星记录、幽禁者相关对白和UI 814/815同时保留。`dlc/evidence.html`可按原文搜索，直接阅读有序上下文、条件，并打开SHA256已对照的原始XML。

幻灯片大多以图像叙事，不能宣称日志描述等于所有画面。路线动作、投影几何、近似洪水时间等另外交叉核对Wiki与玩家讨论，来源保留在数据和原文档案中。Fandom整页抓取可能受robots限制，本轮使用可读的检索正文；有争议的捷径不称为开发者唯一指定路线。

- `learn`：线索指向、学习方法；不是游戏硬门锁。
- `need`：应用机制时的必要条件；储藏库要求三道封印全部解除。
- `alternative`：可选绕路或已知知识后的回访。没有用馆内知识反过来强制要求初次进馆。
- `optional`：幽禁者告别后，再在本体终局邀请其记忆。
- `history`：跨时代的历史先后或因果，不等于玩家探索顺序。

不提供数据挖掘封印密码、速通越界或唯一固定的档案馆访问顺序。明确区分死亡与入睡、现实与模拟、文物与普通提灯、正在运行的循环与停掉循环后的替代结局。
