## 生成入口

在博客根目录执行 `node scripts/outer-wilds-clues/gen.mjs`。`OW_TEXT_DIR`可指定提取语料目录；默认读取本机Vault的`生活/游戏/Outer Wilds/`。这条命令只读取语料，生成专题文件，不执行发布或改写Vault原文。

常规本地预览可在生成后运行`node scripts/build.js`，再用静态HTTP服务打开`dist/outer-wilds-clues/`。本次另在Vault外复制目标文章及必要构建源码，调用相同博客构建器验证返回按钮、嵌入和路径，未覆盖原仓库的`dist/`或既有服务。当前会话的预览端口为59047；服务停止后需重新启动，路径和端口可调整。

- `data.src.mjs`、`index.template.html`及原`assets/graph.js`维护本体地图。
- `dlc.src.mjs`维护DLC的双语解释、逐项原文引用、外部路线来源与联系类型。
- `extend.mjs`解析结构化提取语料，验证对应原始XML的SHA256，生成`nomai/`、`dlc/`，再扩展专题的中英主页面、`graph.json`与`llms.txt`。
- `dlc-route.js`、`dlc-route.css`维护DLC竖向路线图（2026-10-20替换原平移缩放画布）。从上往下是一条可行的发现顺序；桌面端左栏是章节标题、右栏是路线，主线不穿过文字。三座档案馆为三条彩色泳道（档案馆 → 机制 → 封印），汇合到开门；绕路、回访和旁支嵌在出发那一步的卡片里，不画交叉线；历史单独成时间线，循环与替代结局放在最后。每张卡展开后显示说明、中英原文与路线核对来源。精简显示文案仍在`dlc-view.mjs`。嵌入主页面时按内容自动撑高（`postMessage`），没有嵌套滚动。窄屏（<900px）泳道竖排，只画同一栏内的连线。
- `nomai-view.js`、`nomai.css`维护人物关系星图（2026-10-20替换原卡片墙）。左侧深色星图只放人名：按工程与事件分八区（区域划分在`nomai-view.js`的`GROUPS`），颜色表示世代，线型区分亲情、师承、往来、提及，四类可开关；布局为固定种子的力导向模拟，每次加载一致。点人后星图缩放到其关系圈并显示关系标签（放不下的标签隐藏），右栏是人物档案：事迹、按类型分组的关系、共同文本、参与工程，每条可展开中英原文。总览栏有世代图例、全部人物索引、19个工程与口径说明。数据仍逐字取自Vault的`挪麦人物关系图谱数据.json`；Vault中的独立深蓝画布不变。
- `topic.css`维护同页锚点导航和嵌入区域。人物星图为固定高度的深色嵌入框，DLC路线透明嵌入并自动撑高。

## 事实、来源与联系语义

以`中英对照与结构.json`为第一来源，保留外星站全部98条日志文本记录及条件变体；卫星记录、幽禁者相关对白和UI 814/815同时保留。`dlc/evidence.html`可按原文搜索，展开有序上下文、条件，并打开SHA256已对照的原始XML。

幻灯片大多以图像叙事，不能宣称日志描述等于所有画面。路线动作、投影几何、近似洪水时间等另外交叉核对Wiki与玩家讨论，来源在相应节点的纸页内。Fandom整页抓取可能受robots限制，本轮使用可读的检索正文；有争议的捷径不称为开发者唯一指定路线。

- `learn`：线索指向、学习方法；不是游戏硬门锁。
- `need`：应用机制时的必要条件；储藏库要求三道封印全部解除。
- `alternative`：可选绕路或已知知识后的回访。没有用馆内知识反过来强制要求初次进馆。
- `optional`：幽禁者告别后，再在本体终局邀请其记忆。
- `history`：跨时代的历史先后或因果，不等于玩家探索顺序。

不提供数据挖掘封印密码、速通越界或唯一固定的档案馆访问顺序。明确区分死亡与入睡、现实与模拟、文物与普通提灯、正在运行的循环与停掉循环后的替代结局。
