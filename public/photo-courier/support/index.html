Photo Courier Support

Photo Courier runs only on your iPhone or iPad and communicates with an approved agent on the same Wi-Fi. It has no user account or developer cloud.

Quick checks

  1. Keep Photo Courier open in the foreground.
  2. Confirm Photos and Local Network access in iOS Settings.
  3. Make sure the device and agent are on the same Wi-Fi and that the network does not isolate clients.
  4. Start a new connection and check the agent name, source address, and requested access before allowing it.

Support email: alanwang424@gmail.com

When reporting a problem, include the app version, iOS version, device model, and the stable API error code. Do not send photos, access tokens, private IP addresses, or photo identifiers.

照片信使支持

照片信使只在 iPhone 或 iPad 上运行，并与同一 Wi-Fi 中由你批准的 Agent 通信；它没有用户账号或开发者云端。

快速检查

  1. 让照片信使保持在前台。
  2. 在 iOS 设置中确认 Photos 和本地网络权限。
  3. 确认设备与 Agent 位于同一 Wi-Fi，且路由器没有启用客户端隔离。
  4. 重新发起连接，确认 Agent 名称、来源地址和请求读取的内容后再允许。
