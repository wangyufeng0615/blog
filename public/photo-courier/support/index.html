Photo Courier Support

Photo Courier runs only on your iPhone or iPad and communicates with an approved agent on the same Wi-Fi or over a cable. It has no user account or developer cloud.

Quick checks

  1. Keep Photo Courier open in the foreground.
  2. Confirm Photos and Local Network access in iOS Settings.
  3. Make sure the device and the agent's computer are on the same Wi-Fi (and the network does not isolate clients), or connect them with a cable.
  4. Start a new connection and check the agent name, source address, and requested access before allowing it.

Agent skill (optional)

The copied connection details are all an agent needs. If you use Claude Code or Codex, you can also install this skill so the agent knows how to connect and behave:

mkdir -p ~/.claude/skills/photo-courier && curl -fsSL https://wangyufeng.org/photo-courier/skill/SKILL.md -o ~/.claude/skills/photo-courier/SKILL.md

For Codex, use ~/.codex/skills/photo-courier instead.

Support email: alanwang424@gmail.com

When reporting a problem, include the app version, iOS version, device model, and the stable API error code. Do not send photos, access tokens, private IP addresses, or photo identifiers.

照片信使支持

照片信使只在 iPhone 或 iPad 上运行，并与同一 Wi-Fi 或数据线连接的、由你批准的 Agent 通信；它没有用户账号或开发者云端。

快速检查

  1. 让照片信使保持在前台。
  2. 在 iOS 设置中确认照片和本地网络权限。
  3. 确认设备与运行 Agent 的电脑连同一个 Wi-Fi（且路由器没有启用客户端隔离），或用数据线连接。
  4. 重新发起连接，确认 Agent 名称、来源地址和请求读取的内容后再允许。

Agent Skill（可选）

Agent 只需要你复制的连接信息就能工作。如果你用 Claude Code 或 Codex，也可以安装这份 Skill，让 Agent 知道怎么连接、怎么做：

mkdir -p ~/.claude/skills/photo-courier && curl -fsSL https://wangyufeng.org/photo-courier/skill/SKILL.md -o ~/.claude/skills/photo-courier/SKILL.md

Codex 改用 ~/.codex/skills/photo-courier 目录。
