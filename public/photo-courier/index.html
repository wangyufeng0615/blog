照片信使

复制一次连接信息，电脑上的 AI Agent 就能经同一 Wi-Fi 或数据线查找、查看你手机里的照片。每次连接都要你在手机上点“允许”，照片不经过开发者的服务器。

在 App Store 下载

免费，支持 iPhone 和 iPad。中国大陆 App Store 暂不可下载。

怎么用

  1. 打开照片信使，点“复制连接信息”。
  2. 把内容粘贴给电脑上的 AI Agent，比如 Claude Code、Codex、Cursor 或豆包，配置一次就行。
  3. 直接吩咐它，比如“找出我上周末在海边拍的照片”。手机会显示是谁在请求、要看什么，你点“允许”之前，一张照片都不会发出。

隐私与控制

  • 只在前台有效App 打开时才能连接；退到后台立即断开、撤销令牌。
  • 只给你允许的可以手动挑几张照片只给这些；Agent 也可以按相册、收藏筛选，或去掉截图。
  • 本地直传经本地 HTTPS 从手机直接传到电脑，用公钥固定值（pin）防止冒充。没有开发者服务器、账号、广告或统计。
  • 只读不留存不修改、不删除原图；临时副本发完即删。
  • 说明透明发给 Agent 的操作说明（Skill）可以在 App 里逐字查看。

常见问题

怎么和 Claude Code、Codex、Cursor 或豆包配合使用？

在 App 里点“复制连接信息”，把内容粘贴给电脑上的 Agent。里面是本地 HTTPS 地址和这台设备的公钥固定值，Agent 照着连接，你在手机上点允许即可。只要 Agent 能在电脑上发起本地 HTTPS 请求并查看图片就能用，不依赖某个特定工具；能否满足取决于你用的 Agent 及其设置。用 Claude Code 或 Codex 时，还可以选装一份 Skill，让 Agent 知道怎么连接、怎么做。

照片会上传到云端吗？

照片信使没有开发者服务器、账号、广告或统计，照片经本地 HTTPS 直接从手机传到你的电脑。不过，你批准的 Agent 可能按它自己的隐私条款，把收到的照片发给它所用的 AI 服务商；每次批准时，App 都会在按钮上方提醒这一点。

手机和电脑必须连同一个 Wi-Fi 吗？

二选一：连同一个 Wi-Fi（路由器没有开启客户端隔离），或者用数据线把手机和电脑直连。

离开 App 会怎样？

连接只在照片信使处于前台时有效。退到后台会立即断开、撤销令牌，并清除剩余的临时文件。重新打开 App 后，Agent 再次请求、你再次允许即可继续。

支持 iCloud 照片吗？

只存在 iCloud 的照片默认跳过。只有当你在批准卡片上允许了 Agent 的 iCloud 请求，才由 iOS 从你自己的 iCloud 下载；App 本身不连接任何服务器。

会修改或删除我的照片吗？支持视频吗？

不会修改或删除。照片信使只读，临时副本发完即删。目前不支持视频，也不支持后台读取。

支持 隐私政策 Agent Skill

Claude Code、Codex、Cursor、豆包是各自所有者的商标，照片信使与它们没有关联。
